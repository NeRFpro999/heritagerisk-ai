# Multi-Image Assessment Design

HeritageRisk AI will support assessment sessions where a contributor uploads 5–10 images of the same heritage site or damage issue.

The purpose is to let the AI analyse multiple angles together instead of relying on one image.

Workflow:
1. User selects a site.
2. User creates an assessment session.
3. User uploads multiple images.
4. Each image is stored as an observation.
5. The AI analyses all images together.
6. The system creates an assessment-level summary.
7. The rule-based risk scorer calculates the final risk score.
8. A risk case is created or updated.
9. A human reviewer verifies the case.

Important safety rule:
The AI does not make final conservation decisions. It only helps organise visible evidence for human review.
