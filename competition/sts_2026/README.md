# STS Victoria 2026 Evidence Workspace

This directory prepares evidence for the competition category described in the
approved project prompt as `Intermediate Experimental Research`. That category,
the rubric wording, and all administrative rules must be checked against the
current official organizer guidance before submission.

- [Submission checklist](submission_checklist.md)
- [Rubric evidence matrix](rubric_evidence_matrix.csv)
- [Shared competition evidence](../shared/README.md)

The matrix contains the rubric areas and maximum marks supplied in the approved
prompt. It contains no predicted marks. Empty evidence fields must be completed
only after the referenced artifact exists and Albert has verified it.
