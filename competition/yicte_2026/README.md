# YICTE 2026 Evidence Workspace

This directory maps existing evidence to the Young ICT Explorers criteria named
in the approved project prompt. The criteria wording and all administrative
requirements must be checked against current official organizer guidance before
submission.

- [Submission checklist](submission_checklist.md)
- [Criteria evidence matrix](criteria_evidence_matrix.csv)
- [Shared competition evidence](../shared/README.md)

The matrix contains no score prediction. Complete a row only after the evidence
exists, Albert has verified it, and any AI or adult assistance is disclosed.
